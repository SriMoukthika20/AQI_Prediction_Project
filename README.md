# AQI Prediction Project

## Overview
An AI-based system that predicts Air Quality Index using machine learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask

## Machine Learning Model
Random Forest Regressor

## Input Features
- PM2.5
- PM10
- NO2
- SO2
- CO
- O3

## Output
Predicted AQI value

## Running the Project

Install dependencies:

pip install -r requirements.txt

Train model:

python train.py

Run API:

python app.py

Test:

python test_api.py
